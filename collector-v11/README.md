# Collector MVP v11

Aplicatia executabila Collector v11. Documentele canonice de produs si decizii sunt in radacina repository-ului.

## Pornire Windows
Dublu-click pe Porneste-Collector.bat, apoi deschide http://localhost:8000/index-server.html. Lasa fereastra serverului deschisa.

## Teste
Necesita Node.js 18+. Ruleaza npm test din acest folder.

Limitele min/max ale atributelor sunt intervale recomandate: masuratorile reale in afara intervalului se pot inregistra cu avertisment. AI Foundation foloseste un provider mock; nu exista inca provider AI real conectat.
