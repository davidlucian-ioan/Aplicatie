# Collector — MVP

Primul prototip executabil al aplicației.

## Ce demonstrează

- entități generice;
- atribute configurabile;
- evenimente ca sursă de modificări;
- buffer/pending înainte de commit;
- commit atomic la nivel de eveniment;
- istoric append-only;
- funcționare locală fără backend și fără AI.

## Rulare

Deschide `index.html` într-un browser modern.

Datele sunt păstrate în `localStorage` pentru acest prototip.

Acesta este un MVP de validare a fluxului, nu încă produsul final.
